# stephenkrings.com

This repository contains a static snapshot of [stephenkrings.com](https://stephenkrings.com/), including the home page, posts, tag archives, images, stylesheets, feeds, and site metadata.

## Local preview

Serve the files with any static HTTP server, for example:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.

## Publishing

The snapshot is ready to publish as a public repository and can be deployed with GitHub Pages. The original site links and canonical metadata are preserved from the source website.
